# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately using GitHub's "Report a vulnerability" button on this repository's Security tab (private vulnerability reporting), or email hello@tha.run.

Include the Dwight version, your Rhino version, what you did, and what you saw. Do not include API keys, or Grasshopper definitions you cannot share.

You can expect an acknowledgement within 7 days and a fix or a plain statement of why not within 90.

## What counts

Anything that lets a model reply or a crafted definition cause an action the user did not approve, send data that [`docs/public/privacy.md`](docs/public/privacy.md) says is not sent, expose an API key, or execute code without the script having been shown first.

## Supported versions

Only the latest release.
